# Seoul Bike Sharing Demand Data

This repository contains a lecture-use version of the
Seoul Bike Sharing Demand dataset.

## Source

UCI Machine Learning Repository  
Seoul Bike Sharing Demand Dataset

## Modifications for this lecture

The original dataset was filtered to include only observations
with `Functioning Day = Yes`.

The following variables are used in the lecture exercise:

- Rented Bike Count
- Temperature(C)
- Humidity(%)
- Wind speed (m/s)
- Visibility (10m)
- Solar Radiation (MJ/m2)
- Rainfall(mm)
- Snowfall (cm)
- Seasons

## Purpose

This dataset is used for an educational demonstration of:

- Feedforward calculation
- Loss calculation
- Backpropagation
- Gradient-based parameter update
- Basic neural network regression
